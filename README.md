# ANI Talking Cartoon – Android Starter

This is a working Android Studio starter app named ANI.

Included:
- Girl avatar based on the supplied photo
- Hindi/Hinglish voice input using Android SpeechRecognizer
- Hindi text-to-speech
- Animated talking state / mouth cue while ANI speaks
- Chat bubbles
- Demo reply engine

IMPORTANT:
The current project uses a local demo reply function so it can run without an API key.
For real AI conversation, replace demoReply() in MainActivity.java with a call to your own secure backend.
Do NOT put an OpenAI API key directly inside the Android APK.

Open the folder in Android Studio, let Gradle sync, then Run on an Android phone.
